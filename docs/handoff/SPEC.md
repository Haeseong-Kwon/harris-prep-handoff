# 구현 명세

## 목표와 디자인
상담 신청이 단일 전환 목표. 모바일 트래픽 80% 이상을 가정한다. 모브랜드 톡픽의 #0C2340을 기본색으로, #2463EB만 포인트 색으로 사용한다. 흰 배경·연한 중립 배경으로 구간을 구분한다. 제목은 26~48px, 본문은 14~16px, 보조 정보는 최소 11px. 버튼과 입력은 터치 영역 최소 44px. 사진은 라운드 16~18px, 콘텐츠 카드는 12~16px. 반응형 기본 폭 320px부터, 모바일 구간 480px 이하. 시안 콘텐츠 최대 폭 760px. desktop 확장은 개발 협의 대상.

## 진단 인터랙션
1. 기본 상태는 미선택, 답변 영역 숨김.
2. 카드는 단일 선택. 선택한 카드 aria-pressed=true, 나머지는 false.
3. 선택 즉시 답변과 CTA 문구 변경. aria-live=polite로 결과 안내.
4. 선택 고민 문구를 상담 내용 입력란에 반영. 시안은 다른 카드를 선택하면 입력 내용도 변경된다. 실서비스에서는 사용자가 직접 편집한 내용을 덮어쓰지 않도록 selectedConcernId를 별도 보관한다.
5. 맞춤 CTA는 최종 상담 섹션으로 이동. 선택만으로 접수되거나 외부 요청이 발생하지 않는다.
6. 일반적인 진학 시기 고민으로 답변하며 특정 학교 합격이나 효과를 약속하지 않는다.

## 상담 구현 계약
- 시안은 submit 비활성화, 네트워크 전송/저장 없음. 성공 화면 없음.
- 카카오톡 채널 URL은 [자료 대기]. 외부 링크는 확정 후 연결. 전화는 tel:01037908220, 이메일은 mailto:talkpicplus@naver.com.
- 입력: 보호자 성함, 연락처, 자녀 학년(4/5/6), 상담 내용. 자녀 실명·생년월일은 요구하지 않음.
- 필수: 개인정보 수집·이용 동의, 만 14세 미만 자녀 법정대리인 동의. 마케팅 활용/수신 동의는 별도 선택·기본 미체크.
- 정책 확정 시 수집 항목·목적·보유 기간·거부권 및 불이익 안내 전문 제공. 법정대리인 확인 방식 확정 필요.
- 서버 연동 전 결정: 접수 destination, HTTPS endpoint, 책임자, 보안·보유 및 삭제 정책, 중복 접수 및 재전송 처리.
- 실구현: 최소 필수 입력 검증 → 버튼 로딩 → 서버 성공 응답 이후 완료 표시. 실패 시 기존 입력 보존·재시도 안내. 동의 없이 전송하지 않음.
- 개인정보를 URL 쿼리·분석 이벤트·콘솔 로그에 넣지 않음. 분석 도입 여부는 운영자 별도 결정.

## 전환 배치 및 고정바
상단 예약, 히어로, 진단 후 맞춤, 돌봄 이후, 비용 이후, 최종 상담, 모바일 하단 접점. 실제 화면에서는 각 주요 구간에서 2스크롤 이내 CTA 접근을 검수한다. 고정바는 팝업이 아니다. iOS safe-area-inset-bottom, 입력 키보드 활성화, zoom 200%, 320/375/390/480/768px에서 겹침·가로 넘침을 확인한다. sticky header로 앵커를 가리지 않도록 scroll-margin-top 설정. prefers-reduced-motion에서는 부드러운 스크롤을 사용하지 않는다.

## 브랜드·카피 고정 규칙
운영 주체 (주)톡픽글로벌. 상단/하단 톡픽 소속 명시. J&C는 09 한 곳의 현지 협업 파트너만. 운영 주체로 오독되는 표현 금지. 3,900만 원은 예정이며 확정 금액처럼 표기 금지. 근거 없는 후기·순위·성과·학교 추가 금지. 응급 및 야간 대응은 미확정. 유학 수속/입학 대행 표현을 사용하지 않는다.

## 접근성 및 완료 기준
키보드로 카드·FAQ·CTA 접근, 선택 aria 상태 일치, 폼 label 연결, 동의 필수/선택 구분, 오류 role=alert, 이미지 alt 및 촬영 연도 표시. 사진 출처/라이선스 유지. 식별 가능한 사람·실제 학생·대표 이미지의 사용 동의를 별도 확인한다. 확인 대기 항목을 거짓 정보로 대체하지 않는다.
