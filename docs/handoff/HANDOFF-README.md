# HARRIS PREP 개발 전달 패키지

버전: 2026-09-30 / 검토용 디자인 프로토타입

## 열어보기
`index.html`을 Chrome에서 열면 최신 사진 적용 시안을 확인할 수 있습니다. 네트워크 없이도 기본 화면·사진·진단·FAQ가 동작합니다. 인터넷 연결 시 Pretendard 서체를 불러오며, 불가능하면 시스템 서체를 사용합니다.

## 구성
- `index.html`: 독립 실행 시안
- `styles.css`: 시안 스타일. 반복 수정에 따른 CSS 오버라이드를 포함하므로 최종 구현 시 디자인 토큰 중심으로 정리 권장
- `app.js`: 고민 카드 단일 선택, 맞춤 답변, 상담 이동 로직
- `COPY.md`: 섹션별 현재 카피 및 헤드라인 대안
- `SPEC.md`: 레이아웃·컴포넌트·진단·폼·CTA·검수 기준
- `CONTENT-CHECKLIST.md`: 미확정 정보 및 공개 전 확인 자료
- `assets/`: 화면에 사용한 압축 JPEG 사진과 출처·사용 조건

## 구현 범위 구분
현재 시안은 공개·배포 전 검토용입니다. 폼 입력은 서버로 보내거나 저장하지 않습니다. 카카오톡 채널 URL, 개인정보 정책, 환불 규정 및 운영 세부 항목 확인 후 실제 신청 기능을 구현해야 합니다. 전화·이메일 링크는 전달받은 연락처로 연결됩니다.

모바일 고정 상담바는 본 시안에서는 일반 흐름의 하단에 표현되어 있습니다. 실제 웹 구현에서는 SPEC.md에 따라 고정 배치하고 본문 및 키보드 겹침을 처리합니다. 그 외 운영 설명의 [자료 대기] 표시는 최종 공개 전 검토가 필요합니다.

운영 주체는 (주)톡픽글로벌입니다. J&C는 하단 파트너 카드 한 곳에서만 현지 협업 파트너로 표기합니다.
