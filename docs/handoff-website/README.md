# HARRIS PREP 공식 웹사이트 · 개발 전달본
2026-10-02 / 독립 7페이지 정적 시안 / 공개 및 접수 전 검토용

## 확인 방법
압축을 풀고 `index.html`을 브라우저에서 엽니다. 각 메뉴는 별도 HTML 문서로 이동합니다. 별도 설치·빌드가 필요하지 않습니다. 인터넷 연결 없이 사진·메뉴·진단·FAQ가 작동합니다.

## 파일
- index.html: 홈
- program.html: 프로그램 차이·전체 여정·학부모 고민 진단
- school.html: 학교 및 사진
- care.html: 현지 케어
- about.html: 모브랜드·운영진·1기 기록·하단 협업 파트너
- guide.html: 비용·납부·FAQ 8개
- contact.html: 상담 연락처·동의 폼
- styles.css / app.js: 공통 디자인 및 동작
- assets/: 사진·로고·파비콘·이미지 권한 기록
- DEVELOPER-SPEC.md: 페이지와 컴포넌트 명세
- CONTENT-CHECKLIST.md / SOURCE-REVIEW.md: 공개 전 확인 자료
- COPY.md: 실제 구현 카피
- VALIDATION.md: 검증 범위 및 한계

기존 랜딩페이지는 보존했습니다. 이 패키지는 웹사이트 버전의 별도 전달본입니다.

폼은 전송·저장하지 않으며 카카오톡 예약은 연결 대기입니다. 전화·이메일은 전달받은 연락처로 연결됩니다. 실제 접수, 개인정보 정책, 운영 법인, 돌봄·환불 조건을 확정한 후 공개하세요. 모든 페이지의 noindex는 검토용이며 공개 전 검수 후 변경합니다.
